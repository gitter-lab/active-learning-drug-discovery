# PstP screening data
Data used for the PstP iterative screen.
Any use of this data should cite:

[Identification and characterization of inhibitors of the tuberculosis phosphatase PstP](https://doi.org/10.1016/j.jbc.2026.111316).  
Chase Riedel, Jeremy Rahkola, Matthew Reichlen, Hunter Ries, Spencer S Ericksen, Martin Voskuil, Anthony Gitter, Nathan Wlodarchak.  
_Journal of Biological Chemistry_. 302:4, 2026.

The original data is available in [PubChem](https://pubchem.ncbi.nlm.nih.gov/bioassay/2060911).
